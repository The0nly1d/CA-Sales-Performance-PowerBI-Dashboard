# CA Sales Performance & Interactive Business Intelligence Dashboard

**Role & Execution:** BI & Data Analyst.

- **System Scope:** Designed and developed an interactive Power BI sales performance dashboard using Canadian retail sales data to track revenue trends, regional distribution, category contributions, and segment-wise unit sales.

- **Technical Implementation:** Engineered core DAX measures (Total Revenue, Total Units, Average Revenue). Built custom-styled KPI cards, a Line Chart displaying revenue trends over time, a Bar Chart for provincial performance comparisons, a Donut Chart mapping category market shares, a Column Chart for segment unit sales, and integrated an interactive Date Slicer for dynamic cross-filtering.

- **Tech Stack:** Power BI, DAX Measures, Data Visualization, Interactive Slicers, Exploratory Data Analysis.
